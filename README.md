# ¿Cuánto contamina sacar un turno?

Presentación de la defensa oral del primer parcial de Gestión Ambiental (UCEMA, 2 de octubre de 2026).
Balance ambiental de una startup digital, con diVenuo como caso de estudio. Trabajo académico.

**Ver:** https://luciofex.github.io/gestion-ambiental-presentacion-octubre-2026-le/

## Cómo se usa
- Flechas, espacio, clic o swipe para avanzar.
- `N` muestra las notas del orador.
- `F` pone pantalla completa.
- El número de slide va en la URL: `#7` abre la slide de la IA.

Un solo `index.html`, sin build. Las cifras salen del escrito del parcial y sus fuentes están en cada slide.
